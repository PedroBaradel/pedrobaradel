# Olá, eu sou o Pedro Baradel! 👋

### Analista de Dados Sênior | Python | SQL Server | Power BI | ETL | Automação de Dados

Atuo como **Analista de Dados Sênior na Coca-Cola FEMSA**, com foco em transformar dados em soluções analíticas, automações e insights para áreas comerciais e operacionais.

Minha experiência combina **Analytics, Business Intelligence, Automação de Processos e Qualidade de Dados**, utilizando ferramentas como **Python, SQL Server, Power BI, SAP/BW, VBA e Power Automate** para apoiar a tomada de decisão e melhorar a eficiência dos processos.

---

## 🚀 Sobre mim

* 📊 **Analytics & BI:** desenvolvimento de dashboards, relatórios executivos e análises para acompanhamento de KPIs comerciais, operacionais e cadastrais.
* 🛠️ **Automação de Dados:** criação de rotinas em Python, VBA e Power Automate para reduzir tarefas manuais e aumentar a confiabilidade das informações.
* 🔄 **ETL & Integração:** tratamento, validação e disponibilização de dados a partir de fontes como SAP, BW, SQL Server, SharePoint e arquivos estruturados.
* ✅ **Data Quality:** monitoramento de inconsistências, valores nulos, divergências cadastrais e falhas de atualização.
* 📚 **Em evolução constante:** pós-graduando em Data Analytics pela FIAP, com projetos práticos em Machine Learning, Streamlit, séries temporais e storytelling com dados.
* ⚙️ **Atualmente estudando:** Databricks, arquitetura Lakehouse e modernização de pipelines analíticos.
